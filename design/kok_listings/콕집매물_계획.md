# 콕집매물 — 자체 매물 등록·노출 계획 (2026-11-09)

참고: 부동산써브 매물등록 화면(10쪽 PDF), 기존 기획 `design/certified_listings/콕집인증매물_기획.html`(2026-09-05), 코드 실사.

## 0. 한 줄

**중개사는 라운지 매물장의 '직접등록'(private_listings, 117건 이미 있음)을 '콕집매물'로 게시**하고, **일반 회원은 지도에서 로그인 뒤 직거래 매물을 올린다.** 둘 다 같은 표(private_listings)에 쌓고 `poster_kind`(realtor|owner)로 구분. 소비자 노출은 지도 시험판의 비어 있던 "콕집 매물" 칸·핀·단지 서랍부터.

## 1. 지금 있는 것 (재사용)

| 조각 | 상태 | 쓰는 곳 |

**새로 만드는 것은 ① 게시 게이트(공개 전환·점검·만료) ② 일반 회원 직거래 등록 ③ 소비자 노출면(지도·단지 서랍·콕집 자체 상세) ④ 관리자 검수** 네 가지.

## 2. 써브 화면에서 가져올 것 / 뺄 것

가져옴(법정·신뢰 항목):
- 기본: 매물 분류(아파트·오피스텔·빌라·단독·상가·토지 — 우리 표 `type`), 거래(매매·전세·월세·단기)
- 소재지: 시·도/구/동 → 단지 선택(우리 complexes) → 동/호(호는 내부용, 소비자엔 마스킹) / 비단지는 지번+상세
- 가격: 매매가·보증금·월세, **임차권등기명령 여부**, 융자금(표시안함/금액)
- **관리비**: 부과방식(정액·정액(세부 미고지)·기타·확인불가) + 비목별(공용·전기·수도·가스·난방·인터넷·TV, 정액/실비) — 표시광고 세부기준이 요구하는 꼴 그대로
- 매물 정보: 해당층/총층, **층노출 동의(동의→층, 비동의→고/중/저)**, 방/욕실, **방향 기준(거실·안방)+방향**, 현관유형, 복층, 주차 가능·세대당/총 주차, **건축물용도**(대장 기준 자동)
- 시설: 냉방·생활·보안·기타(체크박스 묶음 그대로)
- 상세: 입주(즉시/날짜/협의), 매물특징 40자, 상세 1000자(평·타입 표기 금지 규칙 그대로), 사진 최대 20장·30MB
- 중개업소 정보 자동 표기(법 18조의2) + 연락처 노출 방식(대표번호/휴대폰)
- 검증 방식 개념 → 우리는 **① 자가점검 통과(필수) ② 소유자 확인(선택 배지) ③ 현장확인(선택 배지)**

뺌: 네이버 등록권·건수·패키지(우리는 무료), 다방·KB 연동, 홍보확인서 종류 7가지(우리는 3단계로 단순화), 영업사원 정보.

## 3. 두 갈래 등록

### A. 중개사 (라운지 → 매물장 → 직접등록 → "콕집매물로 게시")
1. 기존 직접등록 폼을 써브 항목으로 **보강**(관리비 부과방식·비목, 층노출 동의, 방향 기준, 임차권등기, 현관유형, 시설 묶음, 입주 유형). 전부 선택 입력은 유지하되 **게시 때만** 법정 항목 필수.
2. "콕집매물로 게시" 누르면: 자동채움(enrich) → 빈칸 안내 → 자가점검(audit 단건) → 통과 시 `visibility='public'`, `published_at`, `expires_at=+30일`. 실패면 초안까지만.
3. 카드에 콕집매물 배지·남은 기간·연장·거래완료(=비공개, 과태료 방어) 버튼. 네이버 광고와 연결된 건은 "네이버에도 광고 중" 표시로 중복 노출 방지.
4. 사진: 기존 업로드·모자이크 흐름 그대로(얼굴·번호판 가림 완료본만 공개).

### B. 일반 회원 직거래 (지도 → 로그인 → 매물의뢰 창 네 번째 탭 "내 집 내놓기")
1. 조건: 로그인 + 휴대폰 인증(이미 있는 PhoneBlock) + **소유자 확인 서류 1장**(등기부 또는 고지서 사진, 관리자 검수) — 사칭·허위 방어. 서류 전엔 "검수 대기"로 비공개.
2. 폼은 중개사 폼의 **축약판**: 단지/주소·동(호는 선택)·거래·가격·면적(단지 평형에서 선택)·층(고/중/저 또는 층)·방향·입주·관리비 총액·특징·사진 최대 10장·연락 방법(전화 공개 / 콕집 안 문의만).
3. 저장: 같은 `private_listings`, `realtor_id=''`, `poster_kind='owner'`, `created_by=user_id`. 1인 동시 2건까지. 30일 만료, 연장 가능.
4. 안전장치: 중개 행위처럼 보이는 문구(수수료·중개) 금지, 하루 등록 한도, 신고 버튼, 관리자가 내리면 다시 못 올림.
5. 법적: 개인 직거래 광고는 공인중개사법 광고 규제 대상 아님(중개업자 아님). 다만 허위광고·개인정보는 우리 약관으로 묶음 → 등록 전 "직거래 안내·동의" 한 장.

### 공통: 콕집매물 조회 구조
- 새 테이블 없이 `private_listings`에 컬럼 추가: `poster_kind`, `published_at`, `expires_at`, `audit_json`, `owner_verified`, `site_verified`, `contact_mode`(phone|kok), `view_count`, `report_count`, `mgmt_*`(부과방식·비목 JSON), `floor_consent`, `direction_base`, `lease_reg`(임차권등기), `entrance`, `facilities`(JSON).
- 공개 API: `GET /kok/listings?bbox|sigungu|complex_no&trade&type` (public만, 소유자 정보·호수 제외), `GET /kok/listings/{id}`(상세+그 단지 실거래·시세·대장 요약), `POST /kok/listings/{id}/inquiry`(콕집 안 문의 → 등록자에게 알림, 번호 비공개 모드).
- 일반 등록 API: `POST /kok/my-listings`(회원), 사진·서류 업로드, 연장·내리기.
- 관리자: `/admin/kok-listings` 검수(소유자 서류 승인·반려, 내리기, 신고 처리).

## 4. 소비자 노출 (지도 시험판 먼저)

1. **매물찾기 레이어**: 콕집매물이 있는 단지 핀에 파란 "콕" 꼬리표, 패널 아래 "콕집 매물" 칸에 지도 안 콕집매물 목록(사진·가격·배지·직거래/중개 표시).
2. **단지 서랍 급매 탭** 맨 위에 "콕집 매물 N" 묶음(이미 `kok` 표시 코드 있음) → 누르면 콕집 자체 상세.
3. **콕집 매물 상세 창**(지도 안 창): 사진·가격·면적·층·방향·관리비·입주·특징·중개사무소(등록번호) 또는 "직거래(소유자 확인됨)" 배지·문의(전화/콕집 문의)·**이 단지 최근 실거래·같은 평형 호가 범위·전세가율** 붙임. 여기가 네이버 딥링크와 다른 지점.
4. 운영 koczip.com: 단지 상세 '매물' 탭에 콕집매물 섹션, 메뉴 '급매·집찾기'에 "콕집 매물" 항목(2차).
5. 필터 바 '매물보기 조건'에 "콕집 매물만" 추가.

## 5. 단계와 일정

| 단계 | 내용 | 기간 |
|---|---|---|
| P1 | 표 확장 + 중개사 직접등록 폼 보강(써브 항목) + 게시 게이트(자가점검·만료·거래완료) + 공개 API | 3~4일 |
| P2 | 지도 노출 3곳(핀 꼬리표·콕집 매물 칸·단지 서랍) + 콕집 매물 상세 창 + 문의 | 3일 |
| P3 | 일반 회원 직거래 등록(지도 안 탭·휴대폰 인증·서류·검수) + 관리자 검수 화면 | 3~4일 |
| P4 | 운영 사이트 노출(단지 상세·메뉴), 알림(관심단지에 콕집매물 등장), 중개사 홈페이지 토글 | 2~3일 |

P1→P2 순으로 하면 중개사 117건이 바로 소비자에게 보이기 시작함.

## 6. 결정 필요

1. **호수 공개**: 기본 비공개(내부 검증용), 소유자 동의 시 공개 — 권장.
2. **일반 직거래 소유자 서류**: 필수(검수 뒤 공개) vs 선택(배지만) — 사칭 방어 위해 **필수** 권장. 검수는 관리자가 하루 1회.
3. **연락 방식**: 직거래 기본값을 "콕집 안 문의"로 두고 전화 공개는 선택 — 권장.
4. **만료**: 30일 자동 만료 + 7일 전 알림 + 1클릭 연장 — 권장(거래 완료 매물 노출 과태료 방어).
5. **중개사 게시 비용**: 초기 무료(기존 방침), 광고 상품은 별도.
6. **시작 유형**: 아파트·오피스텔 먼저(단지·평형·대장 매칭 쉬움), 빌라·단독·상가는 P1 폼엔 들어가되 자가점검 관문은 2차.
