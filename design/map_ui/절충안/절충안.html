콕집 화면 개편 절충안

지도 화면 개편안(2026-11-06)과 공동대표 메뉴 다이어트·매물장 개선안을 하나로 합친 안
작성 2026-11-09콕집 CTO대상: 공동대표·개발상태: 검토용(구현 전)
한 줄 결론. 두 안은 같은 층의 경쟁안이 아니다. 공동대표 안은 무엇을 어떻게 묶을지(정보 구조), 지도 개편안은 그 묶음을 어떻게 보여줄지(표현)를 다룬다. 지도 개편안의 A단계 "메뉴 개편 1단계"에 들어갈 묶음을 공동대표의 5개 카테고리로 교체하고, 공동대표 안에만 있는 등기·전세안심을 지도 레이어가 아닌 상단 버튼으로 얹으면 두 안이 거의 손실 없이 합쳐진다. 매물장 개선 4건은 지도 범위 밖이라 비즈앱 트랙으로 따로 간다.

1. 두 안이 각각 말하는 것

지도 지도 화면 개편안

  • 첫 화면을 지도로 바꾼다. 목록은 지금 보는 지도 범위를 따라 바뀐다.
  • 매물찾기·시세분석·중개사랭킹 세 그룹은 페이지가 아니라 지도 위 레이어다.
  • 표·그래프 통계는 별도 통계 페이지에 지금 모습대로 두고 지도와 양방향으로 잇는다.
  • 콕집요청은 어느 화면에서든 떠 있는 버튼 하나로 누른다.
  • 중개사 랭킹을 단지 서랍·TODAY·사무소 상세 곳곳에 배지로 노출하고, 랭킹 아래에 광고 단지 자리를 만든다.
  • 목록 아래 1/3은 중개사가 직접 올린 콕집 매물 칸으로 예약한다.
  • 현재 상태: testv2.koczip.com에 세 레이어·서랍·역/학교 표시·사무소 핀까지 구현됨.

대표 공동대표 메뉴 다이어트·매물장 개선안

  • 상단 메뉴 12개를 5개 카테고리로 묶는다: ①급매·집찾기 ②등기·전세안심(신규) ③실거래·시세분석 ④콕집AI·매물의뢰 ⑤중개사·커뮤니티.
  • 실거래 19개+ 항목을 4개 탭(실거래가·매물호가추이·시장흐름·투자분석)으로, 중개사랭킹 4개를 정렬 필터 하나로 통합.
  • 특수조건 매물(주인전세·세안고·대출)을 매물호가 맨 아래에서 1번 카테고리 전면으로 승격.
  • 등기·전세안심: 무료 등기분석 + 등기변동 실시간 알림(휴대폰 인증) + 깡통전세지수 + 매수계산기·안전특약. 인스타 광고 랜딩이자 회원 DB 확보 장치.
  • 매물장(비즈앱) 4건: 항목형 광고 입력, 네이버 광고 업로드 항목 맞추기, 조건검색, 내 매물 점검 신설.

5. 등기·전세안심은 열 수 있지만 조건이 있다

공동대표 안의 유일한 신규 콘텐츠다. 절반은 이미 만들어져 있고, 절반은 원가 결정이 필요하다.

항목현재상태·조건
등기변동 알림구축됨회원용 /iros 가 관리자 미리보기로 닫혀 있다. 서버 플래그와 라우트 게이트만 풀면 열린다. 휴대폰 인증(SMS OTP)도 있다. 이상 조회 탐지·텔레그램 경보까지 붙어 있다.
알림 채널부분지금은 웹푸시. 안드로이드 앱·PWA는 받고 아이폰 앱은 못 받는다(네이티브 푸시 없음). 공동대표 안의 카톡·문자로 가려면 알림톡 템플릿 신규 승인과 건당 비용이 붙는다. 알림톡 발송 인프라는 있다.
조회 한도병목등기소 쪽 하루 500회·분당 3회·동시 1건, 조회 1건 약 9초, 회원 하루 3회, 자동 감시 300건 상한. 인스타 광고로 대량 유입을 받으면 첫날 한도에 걸린다. 광고 집행 전에 한도 확장(세션·키 추가)을 등기소 API 쪽과 먼저 합의해야 한다.
무료 등기분석
근저당·전세권·가압류·신탁		없음현재 API는 최근 2개월 신청사건의 변동 여부만 준다. 등기부 전체 권리관계를 읽으려면 등기소 열람 비용이 건당 발생하고 콕집 키의 권한도 바꿔야 한다. "무료"로 열지는 건당 원가·일 한도·어뷰징 대응을 보고 결정. 1차에는 "변동 감시 무료 + 권리분석은 요약 리포트(유료 또는 회원 월 N회)"로 열고, 원가가 확인되면 넓힌다.
안전특약 가이드콘텐츠계약서 작성 기능의 특약 문구를 꺼내 쓰면 된다. 법률 면책 문구 필수.
절충. 안심 버튼은 1차에 등기변동 알림·깡통전세지수·매수계산기·안전특약 네 가지로 열고, 등기분석 탭은 "준비 중·알림 신청"으로 둔다. 광고 랜딩은 등기변동 알림 신청 흐름(주소→휴대폰 인증→감시 등록)으로 잡아 회원 DB 목적을 먼저 달성한다. 한도 확장이 되면 등기분석을 켠다.

6. 매물장 개선안(비즈앱 트랙)

공동대표 안현재처리
항목형 광고 입력자연어·붙여넣기만빠른 입력에 항목형 모드 추가: 주소찾기→거래조건(매매·임대)→기본 항목을 넣으면 나머지는 단지 DB·주소로 자동 채움. 공동대표 피드백대로 중개사에겐 이쪽이 익숙하다.
네이버 광고 업로드 항목첨부 없음제안서의 "유첨"이 파일에 들어 있지 않다. 첨부를 받아야 입력 항목·연결 키를 한 번에 설계할 수 있다.
조건검색·문장형 검색목록만매물장에 지역·금액(보증금/월세)·용도 필터 + 문장형 검색 한 칸. 매물이 많아지면 내 매물도 기억 안 난다는 문제 해결.
내 매물 점검사무소 전체 점검만매물장 물건 ↔ 네이버 매물의 연결 키(매물번호)를 먼저 만들고, 그중 업로드된 것만 점검하는 "내 매물 점검"을 신설. 직원 3명만 돼도 헷갈린다는 요구에 맞춘다.

7. 단계와 순서

A

메뉴 묶기 (공동대표 안 그대로, 지도 없이)

운영 koczip.com 상단 메뉴를 5개 카테고리로 교체. 특수조건 매물 승격, 실거래 4탭, 중개사랭킹 정렬 통합, TODAY 흡수·리다이렉트. 데이터·API 변경 없음. 하루. 이 묶음이 곧 통계 페이지와 지도 레이어의 틀이 되어 버리는 작업이 없다.

B

안심 버튼 1차 + 광고 랜딩

등기변동 알림 회원 오픈, 깡통전세지수·매수계산기·안전특약 묶기, /safe 랜딩. 알림톡 템플릿 신청·등기소 한도 확장 협의 병행. 일주일(한도 협의 제외).

C

testv2 이름·구조 맞추기

레이어·칩 이름을 A단계 명칭으로, 매물의뢰 버튼 세 갈래, 안심·통계 버튼, 지도↔통계 파라미터 연결, 구 단위 랭킹 API. 이미 구현된 세 레이어 위에서 이름과 연결만 바꾸는 일.

D

매물장 개선(비즈앱)

항목형 입력→조건검색→내 매물 점검 순. 네이버 업로드 항목 첨부를 받은 뒤 착수.

E

홈을 지도로

testv2 검증 뒤 운영 홈 전환. 플래그로 되돌릴 수 있게. 단지 상세·통계·랭킹 페이지 주소는 그대로 두어 검색 유입이 끊기지 않는다.

8. 결정이 필요한 것

  • 카테고리 이름: 짧은 이름(매물찾기·시세분석·중개사·안심·통계·매물의뢰)으로 가는 데 동의하는지.
  • 무료 등기분석의 범위: 1차 "변동 감시 무료 + 분석은 준비 중"으로 여는 데 동의하는지, 원가 확인 뒤 무료 여부 재결정.
  • 등기소 한도 확장 협의를 누가 언제 하는지. 인스타 광고 집행은 그 뒤.
  • 네이버 광고 업로드 항목 첨부 전달.
