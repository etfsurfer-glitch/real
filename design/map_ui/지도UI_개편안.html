콕집 지도 화면 개편안

첫 화면을 지도로 바꾸고, 메뉴 개편안의 그룹 중 위치로 보는 것(매물·시세·중개사 랭킹)은 지도 위 레이어로, 표·그래프로 보는 통계는 별도 통계 페이지로 둡니다. 아파트픽의 지도 첫 화면 구조(지도 전체 + 떠 있는 검색·조건·목록, 단지는 지도 위에서 열기)를 따르되, 콕집은 핀에 가격·급매·변동률 같은 숫자를 싣습니다.

한 줄로 보면

메뉴가 레이어가 된다매물찾기·시세분석·중개사랭킹 세 그룹은 페이지가 아니라 지도 위에서 바꿔 끼우는 레이어입니다. 메뉴 개편안의 이름을 그대로 씁니다.
목록은 지금 보는 지도 범위왼쪽 목록(휴대폰은 아래 시트)은 화면에 보이는 영역의 급매·콕집 매물·변동률·중개사 랭킹입니다. 지도를 끌면 목록이 바뀝니다.
요청은 항상 한 번에콕집요청은 어느 화면에서든 떠 있는 버튼(휴대폰은 하단 가운데)으로 누릅니다. 메뉴 개편안의 '요청 보내기는 항상 쉽게'를 지도에서 지킵니다.

단지 상세 화면(90일 방문자 10,672명, 대부분 검색 유입)은 지금 주소 그대로 독립 페이지로 둡니다. 지도에서는 같은 내용을 오른쪽 서랍(휴대폰은 전체 시트)으로 열고, 상세 페이지에는 '지도에서 보기'를 붙입니다.

통계는 별도 페이지로 둔다

지도는 '어디에 무엇이 있나'를 보는 데 좋지만, 전국·시도 비교, 기간 그래프, 긴 순위 표는 지도 범위에 묶이면 오히려 보기 어렵습니다. 그래서 그동안 서비스한 통계·실거래 정보는 통계 페이지에 지금 모습대로 모으고, 지도와는 양쪽으로 잇습니다.

구분내용
지도에 싣는 것위치가 의미 있는 값만: 단지별 실거래가·호가, 동·구 변동률 버블, 거래량 색칠, 갭·전세가율 색칠.
통계 페이지에 두는 것메뉴 개편안의 시세분석 묶음 그대로: 실거래가(최고가·변동률) · 매물호가추이 · 시장흐름(기간별 거래량·단지별 거래량·부동산타임머신) · 투자분석(갭투자·깡통전세지수). 시도·전국 비교표, 기간 그래프, 긴 순위 표.
지도 → 통계시세분석 레이어 목록 끝 '이 지역 통계 전체 보기', 버블·단지 서랍의 '통계로 보기'. 보던 지역(시도·시군구·동)과 칩(예: 호가추이)이 통계 페이지 필터에 그대로 넘어갑니다.
통계 → 지도통계 표의 지역·단지 줄마다 '지도에서 보기'. 시세분석 레이어가 그 위치·같은 지표로 열립니다(?layer=시세&at=&z=).
들어가는 곳데스크톱 오른쪽 위 '통계' 버튼, 휴대폰 하단 탭 두 번째. 지금 통계 페이지 주소는 그대로라 검색 유입·즐겨찾기·기사 링크가 끊기지 않습니다.
좋은 점메뉴 개편 1단계(A)가 곧 통계 페이지의 틀이 되어 버리는 작업이 없고, 지도 쪽은 지도에 맞는 기능만 만들면 돼서 B·C 범위가 줄어듭니다.

매물 목록: 위 2/3 급매, 아래 1/3 콕집 매물

매물찾기 레이어의 목록을 두 칸으로 나눕니다. 위는 지금처럼 수집한 매물 중 급매, 아래는 중개사가 콕집에 직접 올린 콕집 매물입니다. 두 칸 모두 지금 보는 지도 범위를 따라 바뀝니다.

항목내용
비율데스크톱 왼쪽 목록은 높이 2:1(급매 5줄, 콕집 매물 2줄). 휴대폰 시트는 급매 2줄, 콕집 매물 1줄. 시트를 끝까지 올리면 '급매 | 콕집 매물' 탭으로 나뉜 전체 목록.
지도 핀콕집 매물이 있는 단지는 핀 옆에 파란 '콕집' 표시. 급매 할인율 표시와 함께 붙을 수 있습니다.
콕집 매물 표시'콕집' 배지, 올린 중개사무소(랭킹 배지와 연결), 등록일, 확인 방식(현장 확인·주인 직접 의뢰 등), 시세 대비 위치.
직접 등록 전·범위에 0건일 때아래 1/3은 비우지 않고 '원하는 조건을 요청하면 중개사가 찾아 드려요'(콕집요청)와 중개사용 '이 동네에 매물 올리기'(라운지)로 채웁니다.
필요한 것중개사 매물 직접 등록(라운지)·콕집 매물 저장소·지도 범위 조회. 직접 등록은 별도 일정이며, 지도는 자리를 먼저 만들어 둡니다.

중개사 랭킹은 레이어 하나에 가두지 않는다

중개사 랭킹은 콕집에만 있는 콘텐츠라 세 번째 레이어 안에만 두지 않고, 사람들이 지나가는 자리마다 보이게 합니다. 기준(매물 수·업력·직원 수)은 순위 옆에 늘 함께 적습니다.

예상 화면

단계

메뉴 개편 1단계와 지도 전환을 묶되, 홈을 지도로 바꾸는 일은 맨 뒤에 둡니다. 각 단계는 따로 되돌릴 수 있습니다.

  1. A

    메뉴 개편 1단계 (개편안 그대로)

    정리된 시세분석 묶음이 그대로 통계 페이지가 됩니다. 상단 7개 그룹으로 정리합니다. 그룹 이름(매물찾기·시세분석·중개사랭킹)이 지도 레이어 이름과 같아서, 지도로 넘어갈 때 사용자가 다시 배울 것이 없습니다.

  2. B

    지도 셸, 관리자만 보기

    새 주소 /map(또는 ?ui=map 플래그) 뒤에서 만듭니다. 지금 숨겨 둔 매물지도는 숨김 그대로 두고 코드만 참고합니다.

    • 지도 전체 + 떠 있는 검색·레이어·칩·목록·서랍·요청 버튼
    • 시세분석 레이어 먼저, 실거래가 칩부터: 실거래 지도와 동·구 버블 API가 이미 있어 가장 빨리 됩니다
    • 통계 페이지 연결: 통계 화면이 주소 파라미터로 지역·지표를 받아 미리 고르게 하고, 표 줄에 '지도에서 보기'
    • 중개사랭킹 레이어도 같이: 목록은 동 단위 랭킹(/stats/realtors/by-dong)·전국·시도 랭킹을 그대로 씁니다. 구 단위 랭킹 API는 새로 필요합니다
    • 사무소 핀 좌표: 동 랭킹 대상 111,699곳 중 좌표 있는 곳은 57,985곳(52%, 네이버 프로필 좌표). 나머지는 등록 주소를 VWorld 지오코더로 미리 채워 둡니다(비단지 지번 복원과 같은 캐시 방식). 다 채워지기 전에는 좌표 없는 사무소는 목록에만 나옵니다
    • 공유 링크 형식 ?layer=&at=위도,경도&z=&id=
  3. C

    매물찾기 레이어 + 랭킹 배지

    급매·주인매물·맞춤조건을 지도 범위로 부르는 API, 동·구 묶음 집계(급매 수·할인율, 시세분석의 호가추이·거래량·갭 칩 포함)를 새로 만듭니다. 같은 때 단지 서랍 중개사 탭·TODAY TOP 3·사무소 상세에 랭킹 배지를 붙입니다. 목록 아래 1/3 콕집 매물 칸은 이때 자리를 만들고, 직접 등록이 열리기 전에는 요청·매물 올리기 안내로 채웁니다.

    • 묶음 집계는 매일 미리 만들어 두고 읽기만(본 DB에 긴 읽기를 걸지 않음)
    • 한 화면 핀 상한(약 150개), 축소 시 묶음으로
  4. D

    휴대폰 하단 탭

    지도 · 통계 · 요청 · TODAY · 더보기(도구·내 정보·중개사라운지). 요청은 가운데 큰 버튼. 앱(TWA·iOS)에서도 같은 화면입니다.

  5. E

    홈을 지도로 전환

    B~D를 관리자·일부 사용자로 써 본 뒤 /를 지도로 바꿉니다. 지금 홈은 'TODAY' 탭으로 남습니다. 전환 후 4주 지표로 유지·되돌림을 정합니다.

새로 만들어야 하는 것

  • 지도 셸 화면(데스크톱 떠 있는 카드 + 휴대폰 시트·탭바)
  • 지도 범위 목록 API: 급매·주인매물·맞춤조건(bbox 조건)
  • 랭킹 배지: 단지 서랍·TODAY·사무소 상세에 동·구·전국 순위
  • 콕집 매물 칸: 중개사 직접 등록(라운지)·저장소·지도 범위 조회
  • 단지 서랍 중개사 탭 아래 광고 단지 칸(광고 등록·노출 관리)
  • 중개사무소 좌표 채우기(약 5.4만 곳 지오코딩)와 구 단위 랭킹
  • 통계 페이지 ↔ 지도 연결(지역·지표 파라미터, '지도에서 보기')
  • 동·구 묶음 집계: 급매 수·평균 할인율, 호가 변동률, 갭·전세가율
  • 단지 서랍: 단지 상세의 요약·매물·실거래·중개사 탭을 가볍게
  • 요청 창: 단지가 채워진 채 열리는 요청 보내기

  • 카카오 지도(실거래 지도·사무소 지도에서 이미 사용)
  • 실거래 지도와 동·구 버블 API
  • 우리동네 중개사 동 랭킹·전국·시도 랭킹 데이터, 단지별 중개사 매물 수(/complex/{번호}/realtors)
  • 급매·주인매물·맞춤단지 계산 로직
  • 단지 상세 페이지(주소 유지, 검색 유입 보존)
  • 메뉴 개편안의 그룹·이름
  • 지금의 통계·실거래 페이지 전부(통계 페이지로 묶어 주소 유지)

위험과 대응

위험대응
검색 유입 감소단지 상세·실거래 순위 등 지금 주소는 모두 독립 페이지로 유지합니다. 지도는 그 위에 얹는 첫 화면일 뿐입니다.
휴대폰에서 느림핀 상한·묶음 집계 미리 만들기·처음엔 동 묶음만 불러오기. 지도 화면 첫 표시 3초 안을 합격선으로 둡니다.
카카오 지도 호출 한도홈 방문 전체가 지도를 열게 되므로 하루 호출량을 미리 계산해 한도와 맞춥니다.
본 DB 부하지도 범위 질의는 미리 만든 집계·캐시에서만 읽습니다. 본 DB에 긴 읽기를 걸지 않습니다.
중개사 핀 빈자리좌표 없는 사무소(48%)가 지도에서 빠져 랭킹이 틀려 보일 수 있습니다. 목록은 좌표와 무관하게 전체 순위를 보여 주고, 지오코딩을 B 전에 끝냅니다.
광고와 랭킹 혼동광고는 랭킹 칸 아래 별도 칸에만, 항목마다 '광고' 표시. 사무소 광고(돈 내면 위로)는 하지 않습니다.
목록에 익숙한 사용자목록 시트를 끝까지 올리면 전체 목록. 표·그래프로 보고 싶은 사람은 통계 페이지에서 지금과 같은 화면을 그대로 씁니다.

정할 것

  1. 첫 레이어. 매물찾기(급매)를 제안합니다. 메뉴 화면 중 방문자 1위입니다. 만드는 순서는 데이터가 이미 있는 시세분석·중개사랭킹이 먼저입니다.
  2. 홈 전환 시점(E). 관리자·일부 사용자로 써 본 뒤 정하는 것을 제안합니다.
  3. 휴대폰 하단 탭 도입. 요청 버튼을 하단 가운데에 고정하려면 필요합니다. 구성은 지도 · 통계 · 요청 · TODAY · 더보기를 제안합니다.
  4. 그룹 이름 '중개사찾기' → '중개사랭킹'. 랭킹이 콘텐츠라는 게 이름에서 보이게 바꾸는 것을 제안합니다. 메뉴 개편안에도 같이 반영됩니다.
  5. 메뉴 개편 1단계를 지도보다 먼저 할지. 따로 해도 되고, 지도 셸과 한 번에 내도 됩니다.

계획안과 예상 화면이며 홈페이지·코드는 바꾸지 않았습니다. 예상 화면 속 단지·가격·변동률은 배치를 보여 주기 위한 예시 값입니다.
