카카오맵 공용 안내

콕집 → 자매 사이트 · 2026.10.13 · 기준: koczip.com 운영 앱

앱을 새로 만들지 말고, 콕집 앱의 JavaScript 키를 그대로 쓰세요. 우리가 콘솔에 자매 사이트 도메인만 추가하면 끝입니다.

카카오는 2026년 7월 21일부터 무료 쿼터를 개발자 계정의 ‘첫 번째로 활성화한 앱’ 하나에만 줍니다. 자매 사이트용으로 앱을 새로 파면 무료 쿼터가 0이고, 비즈월렛을 연결해 첫 호출부터 과금됩니다. 키를 공유하는 쪽이 정상 경로이고, 카카오 측도 데브톡에서 그렇게 답했습니다.

01전달하는 값

딱 하나입니다.

KAKAO JAVASCRIPT KEY
9a1273ee261418f745229285f7e86021

이 값은 공개값입니다. 지금도 koczip.com 의 JS 번들에 그대로 들어 있어 누구나 개발자도구로 볼 수 있습니다. 비밀이 아니라 도메인 화이트리스트로 보호되는 키라서, 등록되지 않은 도메인에서 호출하면 카카오가 거부합니다.

주지 않는 것

REST API 키 · Admin 키 · 네이티브 앱 키는 전달하지 않습니다. 이 셋은 도메인 잠금이 없어 유출되면 그대로 쓰입니다. 콕집도 쓰지 않아 서버 어디에도 저장돼 있지 않습니다 — 지도는 전부 브라우저에서 JS 키로만 호출합니다.

혹시 자매 사이트에서 서버사이드 지오코딩이 필요하면, 키를 넘기지 말고 콕집 API 에 엔드포인트를 하나 열어 주는 쪽으로 가시죠.

02콕집이 콘솔에서 해줄 일

자매 사이트 쪽에서는 할 수 없습니다. 앱 소유 계정이 콕집이라서요.

developers.kakao.com → 콕집 앱 → 앱 키 → JavaScript 키 → JavaScript SDK 도메인 (예전 메뉴 이름은 앱 설정 → 플랫폼 → Web → 사이트 도메인)에 자매 사이트 도메인을 추가합니다.

등록 규칙

  • 스킴까지 정확히 넣습니다 — https://example.com. http 와 https 는 별개이고, 포트가 다르면 그것도 별개입니다.
  • 서브도메인은 자동으로 안 됩니다. example.com 을 넣어도 www.example.com 은 막힙니다. 쓸 호스트를 전부 나열해야 합니다.
  • 와일드카드(*.example.com)는 비즈앱만 됩니다. 서브도메인이 많이 생길 구조면 비즈앱 전환부터 검토해야 합니다.
  • 개발·스테이징 도메인도 같이 넣습니다. http://localhost:5173 같은 로컬도 등록해야 로컬에서 지도가 뜹니다.

이미 등록돼 있는 것

콕집은 한 키를 이미 두 도메인에서 쓰고 있습니다 — koczip.com(본 서비스)과 real.koczip.com(중개사 홈페이지). 자매 사이트를 붙이는 것도 똑같은 방식이고, 이미 검증된 구성입니다.

한도 주의

사이트 도메인은 앱당 기본 10개입니다. 콕집이 이미 운영·개발 도메인으로 몇 자리를 쓰고 있으니, 자매 사이트가 호스트를 여러 개 요구하면 한도에 걸릴 수 있습니다. 초과분은 앱 Owner 계정으로 카카오에 요청하면 최대 100개까지 풀어 줍니다(심사 있음, 즉시 아님). 그래서 도메인 목록은 한 번에 확정해서 받아야 합니다.

03자매 사이트가 붙일 코드

콕집이 쓰는 로더와 동일합니다. 그대로 복사해 쓰면 됩니다.

// autoload=false → kakao.maps.load 로 명시 초기화(이게 안정적이다)
// libraries=services → 주소·장소 검색을 쓸 때만. 안 쓰면 빼세요(쿼터 절약)
const KEY = "9a1273ee261418f745229285f7e86021";

let sdk = null;
export function loadKakao() {
  if (sdk) return sdk;
  sdk = new Promise((resolve, reject) => {
    if (window.kakao?.maps) return resolve();
    const s = document.createElement("script");
    s.src = `https://dapi.kakao.com/v2/maps/sdk.js` +
            `?appkey=${KEY}&autoload=false&libraries=services`;
    s.async = true;
    s.onload  = () => window.kakao.maps.load(() => resolve());
    s.onerror = () => reject(new Error("카카오맵 SDK 로드 실패"));
    document.head.appendChild(s);
  });
  return sdk;
}

콕집이 실제로 쓰는 범위

참고용입니다 — 아래를 벗어나면 쿼터 계산이 달라집니다.

용도API쿼터 항목

로드뷰·클러스터러·경로탐색·정적지도는 쓰지 않습니다. 자매 사이트가 쓸 거면 미리 알려 주세요 — 경로탐색과 정적지도는 무료 쿼터가 하루 1,000건뿐이라 성격이 완전히 다릅니다.

04쿼터 — ‘같이 쓴다’의 진짜 의미

쿼터는 앱 단위입니다. 두 사이트 사용량이 한 통에 합산됩니다.

API일 무료초과 단가
지도 Web(JavaScript) SDK300,000건0.1원/건
주소로 좌표 변환100,000건0.5원/건
좌표로 행정구역정보 변환100,000건0.5원/건
좌표로 주소 변환100,000건0.5원/건
키워드로 장소 검색100,000건2원/건
경로 조회 · 정적 지도1,000건10원 · 2원/건

여기에 더해 전체 API 합산 월 300만 건 한도가 따로 걸립니다.

현재 여유

콕집 전체 페이지뷰가 하루 1.8만~2.3만입니다(최근 14일 실측). 지도가 안 뜨는 페이지까지 전부 지도 호출로 쳐도 일 쿼터 30만의 8% 미만입니다. 자매 사이트가 들어올 자리는 넉넉합니다.

단, 확인 필요

지도 SDK 호출이 무엇을 1건으로 세는지(스크립트 로드 1회 / 지도 인스턴스 / 타일)는 문서에 명시가 없습니다. 위 수치는 페이지뷰 기준 상한 추정입니다. 콘솔 → 통계 → 쿼터에서 실제 소진량을 한 번 보고 확정하시죠 — 그게 유일한 정답입니다.

가장 큰 리스크

쿼터를 넘기면 429가 떨어지고, 앱 단위라 자매 사이트 사고가 콕집 지도까지 같이 죽입니다. 반대도 마찬가지고요. 무한 스크롤에서 지도를 매번 새로 만들거나, 지오코딩을 캐시 없이 호출하는 코드 한 줄이면 하루치를 태울 수 있습니다.

그래서 두 가지를 조건으로 겁니다 — ① 지오코딩 결과는 자매 사이트 쪽에서 반드시 캐시할 것(콕집도 좌표→주소를 coord_addr.sqlite 에 캐시해 씁니다). ② 트래픽이 10배 뛸 이벤트는 사전에 공유할 것.

05같이 쓰면 따라오는 결합

키 하나를 공유한다는 건 앱 하나를 공유한다는 뜻입니다. 지도 말고도 묶입니다.

  • 카카오톡 공유를 쓸 거면 먼저 말해 주세요. 같은 키로 Kakao.init() 을 하면 공유 메시지가 콕집 앱 명의로 나갑니다(앱 이름·아이콘). 자매 사이트 브랜드로 공유해야 한다면 이건 별도 앱이 맞습니다. 지도만 쓸 거면 Kakao.init() 은 호출하지 마세요 — 지도 SDK는 그게 필요 없습니다.
  • 카카오 로그인도 같은 앱 설정을 봅니다. 동의항목·Redirect URI·비즈앱 심사 상태가 공유됩니다. 자매 사이트가 카카오 로그인을 붙일 계획이면 동의항목이 서로 간섭할 수 있어 설계 단계에서 같이 봐야 합니다.
  • 도메인 10개 한도를 나눠 씁니다(02 참고).
  • 앱 소유권은 콕집에 남습니다. 자매 사이트는 콘솔에 들어올 수 없고, 도메인 추가·쿼터 확인·유료 전환이 전부 콕집을 거칩니다. 운영이 분리될 조직이면 이 점을 먼저 합의해야 합니다.

06체크리스트

순서대로 하면 반나절이면 뜹니다.

  • 자매쓸 도메인을 전부 확정해 전달 — 운영·www·스테이징·로컬 포함. 나중에 추가하면 10개 한도에 걸릴 수 있습니다.
  • 자매쓸 기능 확정 — 지도만인지, 지오코딩·장소검색까지인지, 로드뷰/경로탐색이 있는지.
  • 자매예상 일 페이지뷰 전달(쿼터 합산 계산용).
  • 콕집콘솔 → 앱 키 → JavaScript SDK 도메인에 도메인 추가.
  • 콕집콘솔 → 통계 → 쿼터에서 현재 소진량 확인 후 공유.
  • 자매03 의 로더 붙이고 지도 1장 띄워 확인. 실패하면 콘솔에 401 domain mismatched 가 뜹니다 — 도메인 등록 문제입니다.
  • 자매지오코딩 결과 캐시 적용.
  • 콕집붙은 뒤 1주일간 쿼터 추이 관찰. 일 20만을 넘기 시작하면 유료 전환(비즈월렛)을 미리 준비합니다.

07이럴 땐 앱을 따로 파세요

공유가 항상 답은 아닙니다.

  • 자매 사이트가 카카오톡 공유나 카카오 로그인을 자기 브랜드로 써야 할 때
  • 두 서비스의 운영 주체·정산이 완전히 분리되어야 할 때
  • 자매 사이트 트래픽이 콕집보다 크거나, 일 30만 건을 자체적으로 넘길 규모일 때

이 경우 새 앱은 무료 쿼터가 없으니 비즈월렛 연결 + 첫 건부터 과금을 전제로 잡아야 합니다. 지도 SDK 기준 0.1원/건이라 일 10만 건이면 하루 1만 원 수준입니다.
