# 카카오맵 자매 사이트 공용

`카카오맵_공용안내.html` 이 자매 사이트에 넘기는 문서 전문이다(브라우저로 열면 된다).
공유 링크: https://claude.ai/artifact/AcXiGuEQzTCdQwhXiQ67mR

## 요약

- **앱을 새로 만들지 않는다.** 콕집 앱의 JavaScript 키를 그대로 쓰고,
  콘솔에 자매 사이트 도메인만 추가한다.
  2026.7.21 정책 변경으로 무료 쿼터는 **개발자 계정의 첫 번째 활성화 앱에만** 주어져,
  두 번째 앱은 비즈월렛 연결 + 첫 건부터 과금이다.
- 넘기는 값은 JS 키 하나뿐. REST/Admin/네이티브 키는 넘기지 않는다(우리도 안 쓴다 —
  서버에 저장된 카카오 키가 없다. 지도는 전부 브라우저에서 JS 키로만 호출한다).
- 쿼터는 **앱 단위**라 두 사이트가 합산된다. 지도 Web SDK 일 30만 / 로컬 API 일 10만 /
  전체 월 300만. 넘기면 429 — **한쪽 사고가 다른 쪽 지도를 같이 죽인다.**
- 키 소스는 `frontend/src/lib/kakaomap.ts` 에 고정돼 있다.
  이미 `koczip.com` 과 `real.koczip.com` 두 도메인에서 같은 키를 쓰고 있어
  멀티 도메인 구성은 검증된 상태다.

## 아직 못 채운 칸

자매 사이트의 **최종 도메인 목록**(운영·www·스테이징·로컬)과 **쓸 기능**,
**예상 일 페이지뷰**를 받아야 콘솔 등록을 할 수 있다.
사이트 도메인은 앱당 기본 10개라 한 번에 확정해서 받아야 한다.
