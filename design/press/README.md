# 보도자료·보고서

주제별 폴더에 **생성 스크립트와 산출물(docx·pdf)을 함께** 둔다. 나중에 수치를
현행화할 때 어느 스크립트가 그 문서를 만들었는지 찾을 필요가 없게.

| 폴더 | 내용 |
|---|---|
| `대전-선도지구/` | 대전 노후계획도시 선도지구 발표 전후 매물·호가(세종 비교·3도시 비교 포함) |
| `세제개편안/` | 2026 세제개편안 발표 전후 매물 시장 반응(발표직후·이틀째·**사흘째**·종합·실매물 기준). 사흘째판이 최신 — `calc_tax_reform_days.py` 로 수치를 산출한 뒤 `make_tax_reform_day3.py` 로 조판한다 |
| `반도체벨트/` | 반도체벨트 인구·집값, 대장 아파트 |
| `호가변동/` | 같은 매물의 호가가 오르내린 건수(article_events PRICE_CHANGE) — 주간 인상·인하 통계 |
| `교환매매/` | ‘단지 내 교환매매’가 매물 광고에 실제로 얼마나 나타나는지 전수 조사 |
| `급매-매물동향/` | 급매 비율, 서울 급매 1개월 변화, 광고 vs 물건 |
| `급매/` | 서울 주요 재건축·대단지 9개 평형 전수 — 최저 호가와 호가 중앙값을 갈라 본 급매 실체. 수치는 박스에서 `gm_measure.py`(현 시점 분포)와 `gm_series.py`(콜드 아카이브 32일 호가 추이)로 뽑아 `data/press_gm_*.csv` 에 고정한 뒤 `make_gm_report.py` 로 조판한다. **‘변했다/안 변했다’는 호가끼리 시점 비교로만 말한다** — 호가 대 실거래는 재고 편향 탓에 변화량 근거가 못 된다 |
| `빌라/` | 빌라 매물·동향 |
| `매도인자금/` | 매도인 자금제공·근저당 광고 분석 |
| `전월세시장/` | 전월세 실거래 3년 시계열 — 임대차 4분류(전세·준전세·준월세·월세)·지역·자치구·매물수 vs 실매물수. 박스에서 `full.py`·`listing.py`·`newshare.py`·`chart.py`로 JSON을 뽑아 회수한 뒤, `node build.js`로 주입·PDF 렌더(HTML→A4, playwright). 산출물=PDF 리포트 + 인터랙티브 보도자료 '사라지는 전세' |
| `잠실전월세/` | 잠실 주요 8단지 전월세 — 국토부 실거래 vs 네이버 중복제거(매물수·실매물수·광고배율), 평형별, 주별 매물흐름, 전세 vs 월세. 박스에서 `jamsil.py`~`jamsil4.py`로 JSON 회수 후 `node build.js`. 산출물=사실 PDF(발행 조용호) + 인터랙티브 '잠실 전세, 광고와 실물 사이' |
| `공장매물/` | 전국 공장·창고 매물 전수 — 지역별 규모·3개월 증감(화성 읍·면 포함). 아카이브 parquet 를 nfind 박스에서 받아 `nat2.py`→`rank2.py` 로 산출한다. **지식산업센터 호실 오기재를 거르고 물건 환산한 수치만 쓴다**(안 거르면 순위가 뒤집힘). **체류일수는 이 데이터로 못 잰다** — 광고 번호가 30일 주기로 바뀐다 |
| `회사소개/` | 콕집 서비스 소개 보도자료 |
| `내부-기획문서/` | 배포용이 아닌 내부 검토 문서 |

`data/`·`shots/`·`../fonts/` 는 여러 보고서가 함께 쓰므로 이 폴더 위에 그대로 둔다.
스크립트는 `HERE.parent / "data"`, `HERE.parent.parent / "fonts"` 로 가리킨다 —
새 스크립트를 만들 때도 같은 규칙을 지킬 것.

실행: `python3 design/press/<폴더>/make_*.py`
