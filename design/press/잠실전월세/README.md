## 방법·정의 (재현 시 준수)

- **매물수**=광고 건수, **실매물수**=Σ(1÷same_addr_cnt) 중복제거, **광고배율**=매물수÷실매물수. articles `is_active=1`이 현재분.
- **주별 복원**: `first_seen_date <= 주 <= last_seen_date`로 그 주 활성 매물 집계. 수집 시작 2026.05.18 → 초기 구간 절대수준은 커버리지 영향 → **간격(중복)·추세 방향**으로 해석.
- **평형 밴드**: 전용㎡ 59㎡대(≤66)·84㎡대(67~99)·대형(100+). 전세=B1·월세=B2.
- **실거래**: 국토부, 전세=월세0원. 최근3개월=2026.7~9(9월 신고 진행중), 보증금 중위=중앙값.
- **지역 조인**: articles엔 지역이 없어 complex_no→complexes.cortar_no.
- **신축**(르엘 2026.01·래아 2025.12): 준공 직후로 전월세 실거래 미신고 → 0(매칭 무관 이름검색도 0).
- **발견**: 신축 대형 광고배율 10배 초과(르엘 대형 94→9채), 트리지움 전세매물 5건(실거래 44건/3M), 광고 전세비중 52%>실매물 46%≈실거래 신규 44.5%(교차검증), 전세·월세 동반 감소 위 완만한 월세화(월세비중 48→53%). [[naverreal-jeonse-press]] 계승.
