## 방법·정의 (재현 시 준수)

- **반전세 4분류**(한국부동산원, 비율 기반이라 단위 무관): 전세=월세0 / 준전세(반전세)=보증금>월세×240 /
  준월세=월세×12<보증금≤×240 / 월세=보증금≤월세×12. `rentals`의 deposit·monthly_rent 둘 다 **원** 단위.
- **대표지표=전세 비중(%)** — 신고지연·계절성에 강건. 최근 2개월(2026.8~9) 건수는 잠정 → 라인차트는 2026.8까지.
- **자치구 비교**는 상반기 vs 상반기(계절 통제).
- **매물수 vs 실매물수**: 실매물수=Σ(1÷same_addr_cnt) 중복제거. 광고 기준 전세비중(52.3%)은 부풀려짐,
  실매물 기준(45.9%)이 실거래 신규(44.5%)와 일치 = 별개 출처 교차검증.
- ⚠️ `region_daily_agg` **절대 매물수는 수집 커버리지 확대 아티팩트**라 시계열 금지. §4는 현재 스냅샷 단면만.
- 세제 연표는 발표일·제도·사실만(해석 태그 없음). 인과는 단정하지 않고 데이터가 가리키는 방향으로만 서술.
