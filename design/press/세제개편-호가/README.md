# 세제개편안 전후 서울 아파트 호가 변동 (기자 배포용 원자료)

발표 **2026-08-03 18시**. 각 10일 대칭 구간 + 대조군.

| 구간 | 기간 |
|---|---|
| 대조군 | 7/14~7/23 |
| 발표전 | 7/24~8/02 |
| 발표후 | 8/04~8/13 |

**8/03 은 통째로 제외** — 18시 발표라 하루 안에 전후가 섞인다(그날만 인하 75%).

## 무엇을 셌나
`article_events(PRICE_CHANGE)` — **같은 매물번호의 호가가 바뀐 사건**만. 신규 등록·매물 회수는
포함하지 않는다. 지표는 **인상률 = 인상 ÷ (인상+인하)**.

가격대는 **매물마다 전 기간 첫 관측 호가 하나로 고정**했다. 이벤트마다 old_price 로 나누면
값을 내린 매물이 아래 구간으로 옮겨가 저가 구간에 인하가 쌓인다(순환논리).

## 산출물 (design/press/data/)
| 파일 | 내용 |
|---|---|
| `press_tax_overall.csv` | 전국·서울·강남3구·서울(강남3구 외) |
| `press_tax_band.csv` | 서울 가격대 5구간 |
| `press_tax_gu.csv` | 서울 자치구 24곳 |
| `press_tax_cross.csv` | 자치구 × 가격대 교차 |

## 핵심
**분기선은 20억이 아니라 15억이다.** 10억 미만은 미동이 없고(−0.5p), 10~15억은 오히려
반등(+8.0p)했으며, 15억을 넘으면 전부 두 자리로 무너졌다.
**가장 크게 다친 구간은 30억 이상이 아니라 15~20억**(대조군 대비 −23.5p)이다.

## 쓸 때 주의
1. **대조군 없이 전후만 비교하면 틀린다.** "비싼 집일수록 호가를 덜 올린다"는 7월 중순에도
   이미 그랬다(10억 미만 49.6% vs 30억 이상 26.4%). 발표가 만든 건 서열이 아니라 **격차**다.
2. **자치구 표는 표본이 얕은 구가 극단값을 만든다.** 도봉 −28.0p(합계 336건)·강북 +16.6p(284건)은
   신뢰구간 밖으로 봐야 한다. 서초 −26.8p(2,075건)는 안정적이다.
3. **진짜 축은 지역이 아니라 가격대다.** 교차표에서 비교 가능한 7개 구 중 6곳이 같은 구 안에서도
   저가 구간이 고가 구간보다 덜 빠졌다.
4. **호가는 실거래가 아니다.** 부동산원 주간지수(거래 기반)와 나란히 놓으려면 호가가 먼저 움직이고
   거래가 따라온다는 시차를 밝혀야 한다. 8월 계약분은 30일 신고제라 9월 초에야 집계된다.

재현: `python3 measure.py` (박스에서 실행, /tmp/tax_csv/ 에 생성)

# [보완] 동일 물건 패널 — 호가 '수준'으로 본 비교 (`measure_panel.py`)

위 통계는 **값을 고친 사건**을 센다. 값을 안 고친 집은 분모에 없다. 그래서
"인상률 −23.5p"가 곧 "호가가 그만큼 내렸다"는 뜻은 아니다. 이 패널이 그 빈자리를 메운다.

## 동일 물건 판정
한 집을 여러 중개사무소가 올리면 광고가 여러 건이다(전국 아파트 매매 광고 126만 → 물건 52만).

키 = **단지 + 동 + 층 + 전용면적 + 향 + 공급면적**. 호가는 키에 넣지 않는다 — 넣으면 값이
바뀐 순간 다른 물건이 돼 패널이 끊긴다. 같은 키에 광고가 여럿이면 호가의 중앙값을 쓴다.

| 후보 키 | 물건 수 | 네이버 `Σ1/same_addr_cnt`(52.6만) 대비 |
|---|---|---|
| 단지+동+층+전용 | 43.1만 | 81.0% — 같은 층 다른 호를 합침(호가 괴리 최대 99%) |
| +향 | 51.4만 | 96.4% |
| **+향+공급면적 (채택)** | **52.1만** | **97.8%** |

## 구간 (양끝 스냅샷을 잇는 10일)
| 구간 | 기간 |
|---|---|
| 대조군 | 7/13 → 7/23 |
| 발표전 | 7/23 → 8/02 |
| 발표후 | 8/02 → 8/12 |
| 민감도 | 8/03 → 8/13 |

매물 수집은 11시·19시다. 8/03 스냅샷은 발표(18시) **뒤**라, 마지막 온전한 발표 전 상태는
**8/02**다. 기준점을 8/03 으로 바꿔도 순서·부호가 그대로임을 민감도 열로 확인했다.

## 산출물 (design/press/data/)
`panel_overall.csv` · `panel_band.csv` · `panel_zone.csv` · `panel_gu.csv` ·
`panel_cross.csv` · `panel_stock.csv`

## 핵심 — 두 통계가 말하는 것이 다르다
**호가 수준 자체는 거의 안 움직였다.** 서울 전체 물건의 평균 호가 변동은 발표 후 10일 −0.04%,
가장 큰 30억 이상도 −0.26%다. 서울 물건의 **93%는 열흘 동안 호가를 한 번도 고치지 않았다.**

움직인 것은 **값을 내리는 물건의 비율**이고, 그것도 위쪽에 몰려 있다.

| 가격대 | 인하 물건 비율 (대조군→발표전→발표후) | 대조군 대비 |
|---|---|---|
| 10억 미만 | 4.1 → 3.9 → 3.3% | −0.8p |
| 10~15억 | 4.4 → 3.9 → 3.8% | −0.6p |
| 15~20억 | 5.6 → 4.7 → 4.7% | −0.9p |
| 20~30억 | 5.9 → 6.2 → 6.7% | **+0.8p** |
| 30억 이상 | 9.2 → 10.5 → 13.1% | **+3.9p** |

**분기선이 지표마다 다르다.** 인하 물건 비율이 늘어난 구간은 **20억 위**뿐이다.
평균 변동률의 부호가 바뀌는 자리는 **15~20억**(+0.06% → −0.00%)이다. 둘을 섞어 쓰면 안 된다.

지역도 같은 결이다. 자치구 25곳에서 **중앙 호가와 인하 비율 변화의 상관 r = +0.68**
(서초 36억 +3.8p ↔ 강북 7.5억 −2.9p).

## 쓸 때 주의
1. **위 통계와 숫자를 섞지 말 것.** 사건 기준 인상률(강남3구 36.4%→16.3%)과 패널 기준
   인하 비율(8.8%→11.4%)은 분모가 다르다. 사건 통계는 '고친 사람들 안에서의 구성',
   패널은 '전체 물건 중 몇 %가 내렸나'다.
2. **생존편향은 결론과 반대 방향이다.** 10일 뒤에도 남아 있는 비율은 10억 미만 89.0%,
   30억 이상 94.1% — 저가가 더 많이 빠진다(팔리거나 거둬들임). 남은 저가 매물은 '안 팔린 것'
   쪽으로 치우치는데도 값을 덜 내렸다. 편향이 결론을 만들어낸 게 아니다.
3. **재고는 전 구간에서 늘었다.** 서울 물건 수 8/02→8/12: 10억 미만 +1.8%, 10~15억 +4.3%,
   15~20억 +5.5%, 20~30억 +4.6%, **30억 이상 +6.8%**. 고가가 가장 빠르게 쌓인다.
4. 호가는 실거래가 아니다(위 4번과 동일).
