# 뉴스레터 — 서울 59㎡ · 12억 이하 · 500세대 이상

기준일 2026-08-07 · 단지 286곳 · 자치구 19곳

## 조건
- 서울(sgg_cd 11xxx) 아파트
- 전용 58.0~60.5㎡ (단지마다 58.7·59.2·59.9 로 갈려 있어 '59타입'을 이 범위로 묶었다)
- 최근 6개월 매매 실거래의 **중앙값**이 12억 이하 (평균은 특이 거래에 휘둘린다)
- 총 500세대 이상
- 해제(취소)거래 제외 — 넣으면 없던 신고가가 시세처럼 섞인다

## 만드는 법
데이터는 운영 박스에서 뽑는다(`transactions` + `complexes` + `listings_current`).
`nl59.json`(뉴스레터용 집계) · `nl59_full.json`(엑셀용 상세) · `nl59_ask.json`(호가).

    python3 design/newsletter/make_seoul59.py      nl59.json nl59_ask.json 뉴스레터.html
    python3 design/newsletter/make_seoul59_xlsx.py nl59_full.json 단지목록.xlsx

## 개인정보
엑셀은 **단지**를 정리한 것이지 매물이 아니다. 소유자·임대인·세입자 이름과 연락처,
중개사무소 이름·등록번호·연락처, 담당자, 매물 단위 정보는 넣지 않는다. 검증 스크립트로
전수 확인한다(`읽는 법` 시트의 '넣지 않은 것' 문장만 걸리는 것이 정상).

## 안 넣은 것
- 난방방식: 원천이 코드(HT001 등)로만 주고 뜻이 확인되지 않아 뺐다. 모르는 값을 채우지 않는다.
- 건폐율·주차 등 0으로 온 값: '없음'이 아니라 '모름'이라 빈 칸으로 뒀다.
