# 재설계 (같은 날, 2차)

1차가 **더 구려졌다**는 피드백을 받았다. 맞는 지적이었다. 원인은 하나다 —
1:1 안전영역을 맞추겠다고 머리띠를 330 → **396px** 로 키웠고, 그만큼
데이터 영역이 깎였다. 이 템플릿은 *숫자가 크게 때리는 것*이 전부인데
그 자리를 내가 가져간 것이다. 본말전도였다.

격자(데이터) 영역 실측 — 같은 카드, 같은 데이터 기준:

| | 격자 높이 | |
|---|---|---|
| 원본 | **757px** | |
| 1차 | 709px | −48 (더 좁아짐) |
| 재설계 | **743px** | −14 (사실상 복구) |

## 무엇을 바꿨나

- **띠를 396 → 324px 로 되돌리고**, 출처·분류·브랜드 줄을 띠 *바깥* 흰 바탕으로
  내렸다. 띠가 제목만 지면 바닥정렬로도 제목 윗변이 y≈141 이라 안전선을 넘는다.
  예전 굵은 구분선(rule) 자리를 대신하므로 높이도 거의 안 먹는다.
- **사진 없는 카드는 어두운 그라디언트 대신 얇은 색 리본(112px)** 만 깔고,
  제목은 흰 바탕에 검게 쓴다. 1차의 전면 다크 밴드가 카드를 무겁게 만들었다.
  리본에는 작은 워드마크를 넣어 '제호'로 읽히게 했다.
- **푸터의 꽉 찬 그라디언트 띠를 걷어내고** 선 하나 위에 가볍게 올렸다.
  색면이 크면 정작 데이터가 뒤로 밀린다.
- **칸의 테두리를 없앴다**(2~3px 선 + 라운드 20 → 라운드 16, 선 없음).
  모든 블록에 같은 테두리·그림자를 주면 위계가 평평해진다.
- 제목은 데이터에 자리를 내주고 한 단계 물러섰다(122 → 104px).

1차에서 **유지한 것**: 등락↔상태 팔레트 분리, 카드별 색, 워터마크 1개,
Pretendard 900 제목, 뉴스 썸네일 폴백, 하단 2층 → 1층.

비교 이미지 `before_after.png` 는 원본 · 1차 · 재설계 3단 비교다.

# 브랜드 컬러 환원 (3차)

카드 종류마다 다른 색(줍줍 앰버·달력 보라·LH 그린·신고가 레드…)을 준 것은
**폐기**했다. 피드에서 구분은 됐지만 콕집 카드로 안 보였다. 브랜드 색은 흩뜨리지 않는다.

- 모든 구조색(머리띠·리본·순번 배지·인용구 세로줄·브랜드 칩·구분선)을
  **콕집 블루 `#1268d3`** 하나로 통일했다. `cards.js` 의 `ACCENT` 표는 남겨 뒀지만
  값이 전부 `BRAND` 라 한 곳만 고치면 된다.
- 토큰 값을 `frontend/src/styles.css` 와 맞췄다 — 카드와 사이트가 다른 파랑·다른
  빨강을 쓰면 같은 브랜드로 안 읽힌다.
  `--ink #16202e` · `--brand #1268d3` · `--red #d23b3b`(--c-up) ·
  `--blue #1268d3`(--c-down) · `--brand-soft #e8f0ff`.
- 형광 노랑(`--hl-y`)을 전부 걷어냈다. 콕집 색이 아니다.
  사진 위 제목은 강조색 없이 흰 글씨로 간다 — 사진이 이미 시선을 잡는다.

## 색을 안 쓰면 카드 종류는 무엇으로 구분하나

색이 아니라 셋이 맡는다.

1. **사진 아트디렉션** — 줍줍은 야간, 청약은 아침 (개선안 ⑤, 애셋 작업)
2. **골격** — 격자 · 포디움 · 달력 · 목록 · 병렬 빅넘버 (개선안 ⑥)
3. **카테고리 배지** — 무순위청약 / 청약정보 / 시장지표 …

## 브랜드 색이 아닌 채로 남긴 것 (의도)

- **등락**: 상승 빨강 / 하락 파랑 — 시장 관행이고 사이트 토큰과 같다.
- **접수 임박**: 앰버 `#e08a1e` 계열 — 사이트 `--c-warn` 과 같은 역할.
- **달력 범례**: 청약 파랑 / 당첨발표 보라 / 임대마감 초록 — 세 갈래를 가르는
  범례지 장식이 아니다. 하나로 합치면 달력을 못 읽는다.

# 배경 사진 교체 + AI 티 제거 (4차)

## 왜 바꿨나

예전 네 장은 한눈에 AI 생성물이었다 — 과하게 맑은 하늘, 완벽한 대칭, 유리 광택,
사람도 차도 흔적도 없는 비현실적 청결함. 게다가 넷이 서로 비슷해 날짜로 돌려도
바뀐 티가 안 났고, **16:9 를 3.3:1 띠로 잘라 쓰느라 위쪽 절반이 하늘만 남았다.**

## 새 사진

Artlist(Nano Banana 2.1, 웹서치 켬)로 **2024~2025 준공 신축 단지**를 다큐멘터리
사진처럼 생성했다. 8장 뽑아 4장을 골랐다. 560크레딧 × 2회.

- `apt_day1.jpg` · `apt_day2.jpg` — 흐린 오후, 단지 내 보행로
- `apt_dusk1.jpg` · `apt_dusk2.jpg` — 블루아워, 로비 불빛과 일부 세대만 점등

프롬프트에서 중요했던 것:
- **"no text, no signage, no lettering"** — 안 넣으면 가짜 한글 간판이 박혀 못 쓴다
- **"not CGI, not architectural visualisation"** + 실사 단서(유리 얼룩, 고르지 않은
  포장 줄눈, 지지대 묶인 조경수, 센서 노이즈, 비대칭 프레이밍)
- **왼쪽 절반은 하늘·보행로로 비울 것** — 제목이 앉는 자리다
- 사람·차량 제외(초상·번호판 문제도 같이 피해 간다)

**띠 비율(3.33:1)로 미리 잘라서(2160×648) 넣는다.** CSS 가 세로를 임의로 깎던
문제가 사라졌고, 구도를 우리가 정한다.

## 같이 바꾼 것

- **베일을 세로 → 대각선으로.** 아래로 갈수록 어두워지는 그라디언트 하나로 전부
  덮으니 사진이 통째로 탁해지고 건물 쪽까지 가라앉았다. 이제 **제목이 앉는 왼쪽만**
  가로로 누르고 세로는 바닥만 살짝 받친다. 오른쪽 건물·조명이 살아난다.
- **워터마크 완전 제거.** 7개 → 1개로 줄였다가 아예 뺐다. 사진 위에 찍힌 반투명
  핸들은 그 자체로 '기계가 찍어낸 것'으로 읽힌다. 브랜드는 띠의 koczip.com 칩과
  하단 브랜드 줄이 이미 두 번 진다.

옛 사진은 박스 `assets/bg_old/` 에 남겨 뒀다. 새 네 장은 이 레포 `bg/` 에도 복사.
