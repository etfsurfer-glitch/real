# 카드뉴스 v2 — 1차 적용 (2026-10-13)

개선안 PDF(`콕집_카드뉴스v2_이미지개선안.pdf`)의 **1차 + 일부 2차**를 반영했다.
대상은 nfind 박스 `/opt/koczip-carosell` 의
`lib/render/onepage.js`, `lib/compose/cards.js` 두 파일.

착수 전 박스에 `git init` 하고 baseline 을 커밋했다(레포가 아니라 박스에만 있다).
되돌리려면 `git revert` 또는 `git checkout 0fc2036 -- lib/`.

| 항목 | 한 일 |
|---|---|
| ① 1:1 안전영역 | 머리띠(396px)를 만들어 제목·부제·출처·배지를 전부 y>135 로 내렸다. 띠 안에 **koczip.com 노란 칩**을 넣어 프로필 격자에서도 브랜드가 남는다. |
| ② 카드별 구분 | 카드 11종에 `accent` 를 달고 순번·칩·인용구·브랜드바·띠 색을 전부 그 색으로 묶었다. 줍줍=앰버, 청약=블루, 달력=보라, 시장/뉴스=먹색. |
| ③ 색 의미 분리 | `ddayChip` 이 `dir`(등락) 대신 `tone`(상태)을 돌려준다. 상태 칩 `t-urgent/t-soon/t-normal` 신설, **상태 카드의 금액은 먹색 고정**. 빨강·파랑은 이제 등락 전용. |
| ④ 워터마크 | 7개 → 1개. 사진 띠 안(글자 없는 자리)으로 옮겼다. |
| ⑦ 제목 | Black Han Sans → **Pretendard 900**, 6px 오프셋 그림자 제거. 띠가 늘 어두우므로 제목은 항상 흰 글씨, 강조는 형광 노랑. |
| ⑧ 뉴스 썸네일 | 기사 사진이 없으면 카드 색 패턴 타일을 깐다 — 줄마다 본문 폭이 달라지던 톱니가 사라졌다. |
| ⑨ 하단 압축 | 노란 경고 박스 + 꼬리말 2층 → 카드 색 세로줄 인용구 1층. `.tail`·`.brandbar` 에 `flex-shrink:0`. |

부수 수정: `.stats` 넘침 가드(오늘의 시장에서 마지막 줄이 인용구와 겹쳤다),
브랜드바 슬로건이 앰버·보라 배경에서 안 읽히던 노랑 → 흰색 대비로 교체.
